## 🌟 Key Features

### 1. Kinetic Nanite `<SwarmLoader />`
- **Brownian Flocking Field**: 2,200 luminescent nanite particles in chaotic orbital vortex drift.

- **Liquid Mercury Interaction**: Hovering cursor dynamically displaces particles with magnetic containment.
- **Forward Warp Dive**: Hyper-speed camera acceleration transition into the main viewport with audio harmonic burst.

### 2. Motion Graphics Hero Section
- **Live Status Beacon**: Pulsing emerald pill badge indicating active multimodal status.
- **Staggered Kinetic Reveal**: *"Think in Any Modality. Built for Universal Flow."* broken down into character-level physics animations.
- **Interactive 3D Gemini Tensor Core**: Multi-axis gyroscopic orbitals with 3D cursor perspective warp (`rotateX`, `rotateY`, `scale`) and live 2M token telemetry HUD.
- **Magnetic Glassmorphism CTAs**: Spring-damped buttons with cursor-following inner glow flares and Web Audio sound triggers.

### 3. Four Pillars Bento Grid (`<ManifestoGrid />`)
- **01. Native Multimodal Audio & Vision**: Interactive 24kHz stream waveform visualizer reacting to scroll velocity and audio/vision/video stream modes.
- **02. Infinite Context & Code Synthesis**: Real-time terminal demonstrating Gemini 4 / 2.5 Pro auditing large codebases across 2,000,000 tokens with `ThinkingLevel.HIGH`.
- **03. Autonomous Deep Reasoning**: Interactive living agent graph demonstrating Gemini orchestrating real-time Google Search Grounding and sandboxed Code Interpreter execution.
- **04. Gemini Flash Velocity**: 3D tilt physics card with sub-second latency and 1,000,000 tokens/sec throughput.

### 4. Multimodal Reasoning Lab (`<PromptSynthesizer />`)
- Interactive sandbox featuring **Gemini 4 Argon**, **Gemini 3.8 Live**, **Gemini 3.8 Flash**, and **Gemini Pro Vision**.
- Real-time HTML5 Canvas visualizer rendering cross-attention tensors, Fibonacci acoustic spirals, and vector manifolds.

### 5. Sensory & Visual Aesthetics
- **Filmic Noise Overlay**: Viewport-wide SVG `<feTurbulence>` fractal noise overlay (`mix-blend-mode: overlay`) for a high-budget filmic texture.
- **Magnetic Follower Cursor**: Smooth-damped cursor with adaptive states for buttons ($2.1\times$), cards ($2.4\times$), and text inputs.
- **Ambient Flow Soundscape**: Native Web Audio API binaural synthesizer (528 Hz transformation frequency) with user audio toggle.
- **Lenis Momentum Scroll**: Silky 120 FPS inertial scrolling with custom damping curves.
